# comma-command (Rust crate placeholder)

This crate reserves the `comma-command` name on crates.io for the
[comma-command project](https://github.com/by3hak/comma-command).

The usable implementation is currently the Python CLI (`pip install comma-command`).
This Rust crate contains no command-line binary or supported API yet; do not add it
as a dependency expecting functionality. A native Rust implementation may be
published in a future version.
